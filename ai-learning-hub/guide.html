DOCUMENTATION / HOW TO EXTEND

讓下一篇筆記，
也遵守同一套規則。

這不是只適用一次的網頁模板，而是一套可交給 AI 閱讀、理解、重複執行的內容生產流程。

PROJECT PRINCIPLE

規則先行，內容一致，設計可延伸。

查看成果 →
STEP 01

閱讀 AGENTS.md

在新增或修改任何檔案前，AI 必須先讀取根目錄的 AGENTS.md，確認資料結構、命名規則、排版和品質要求。

STEP 02

新增一筆結構化資料

只需在 data/notes.json 中新增一筆物件。每筆筆記包含 slug、title、category、summary、tags 與 sections 等一致欄位。

EXAMPLE / notes.jsonJSON
{
  "slug": "new-ai-topic",
  "title": "新的 AI 主題",
  "category": "生成式 AI",
  "summary": "用一句話說明重點。",
  "tags": ["概念", "入門"],
  "level": "入門",
  "readMinutes": 4,
  "updated": "2026-11-09",
  "sections": [
    {
      "heading": "核心概念",
      "paragraphs": ["清楚說明概念與用途。"]
    }
  ]
}
STEP 03

沿用現有頁面，不重造輪子

首頁程式會自動從 JSON 產生卡片、分類與搜尋結果。文章詳細頁使用相同版型顯示新筆記，不需要為每篇文章重新複製 HTML。

STEP 04

檢查內容並發布

執行 python scripts/validate_notes.py 確認 JSON 格式、分類、日期與 slug 沒有錯誤；再檢查手機版和文章連結，最後推送到 GitHub。

可以怎麼向 AI 下指令？

「請先閱讀 AGENTS.md，再幫我新增一篇『Self-RAG 入門』筆記。遵守現有欄位和分類，內容包含核心概念、基本流程、適用情境及練習題；完成後執行資料驗證，且不要修改既有頁面樣式。」
